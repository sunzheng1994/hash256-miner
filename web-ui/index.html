方案 A

本机网关 + 云端 PoW + Flashbots Bundle

浏览器只访问本机 http://127.0.0.1:8790。钱包私钥与 Flashbots 身份私钥仅通过本机环境变量读取，不会出现在表单或网络请求体中。

本机：读链 → 把 challenge 发给 云端 Worker 算 nonce → 本机签名 mine(nonce) → 向 Flashbots relay 提交 bundle。
云端：只接收公开 PoW 参数，不接触私钥（需 X-API-Key 与 HTTPS/内网）。
