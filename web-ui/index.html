HASH256 本地挖矿 / Flashbots Bundle

本页只调用 http://127.0.0.1:8790 上的本地网关。钱包私钥与 Flashbots 身份私钥只放在本机环境变量（见 README），浏览器不收集私钥。

（结果将显示在此处）
1. 先在阿里云运行：REMOTE_MINER_API_KEY=xxx hash256-remote-worker --host 0.0.0.0 --port 8787（并开放安全组端口）。
2. 本机：export HASH256_PRIVATE_KEY=... 与 export FLASHBOTS_AUTH_KEY=... 后执行：hash256-local-ui --port 8790。
3. 用浏览器打开本页（可通过网关根路径 / 直接打开此 HTML）。
